Evaluación del clasificador y del color

Evalúa el modelo tal como lo usa la app (ONNX int8 en el navegador, preprocesado, calibración y color de la app) con un conjunto local preparado por node scripts/eval-prepare.mjs en public/test-photos/, que no se sube al repositorio. Ejemplo: ?set=eval-clothing-dataset-test&auto; añade &colors para evaluar solo las fotos con colores de referencia (también recorta, como el formulario) &limit=20 para una prueba corta y &nocut para no recortar. La memoria (de la página y sus workers) solo se mide en Chrome con aislamiento entre orígenes. Para medir con varios hilos, como en producción: MOLT_BENCH=1 npm run build y npm run preview.
